This is a Recipe Finder web application that allows users to seach for recipes by
ingredient,category, or name. The application fetches data from TheMealD8 application
and displays the results. Users can view detailed recipes, watch videos on the recipes,
and save their favorite recipes.

Key features:
    Multiple search options
    Recipe viewing with instructions and YouTube links
    Favorite recipe saving with local storage
    Dark mode
    Responsive design

Features Implemented 

    Search Functionality
        Three search modes: by ingredient, by category, and by name
        Dynamic API 
        Error handling for no results found

    Recipe Display 
        Grid layout of recipe cards with images
        Detailed recipe modal with:
            Preparation instructions
            Category information
            YouTube link (when available)
            High-quality image


    Favorites System
        Heart icons to favorite/unfavorite recipes
        Local storage persistence of favorites
        Dedicated favorites view
        Visual indication of favorited recipes


How to Run the Project
Option 1: Open Directly in Browser
    Download the project files (HTML, CSS, and JavaScript)

    Open the index.html file in any modern web browser

Option 2: Run with Live Server (for development)
    Ensure you have Node.js installed

    Install Live Server globally:

    npm install -g live-server
    Navigate to the project directory in your terminal

Run:

    live-server
    The application will open automatically in your default browser

    Requirements
    Modern web browser (Chrome, Firefox, Edge, Safari)

    Internet connection (for API calls)
